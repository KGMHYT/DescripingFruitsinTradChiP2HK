# 水果形容小達人

給香港小學二年級學生的繁體中文水果描述遊戲。以士多啤梨、香蕉、橙、蘋果、奇異果和提子練習名稱、顏色、味道、「又……又……」句式和特徵推理。

## 開始遊戲

直接在瀏覽器開啟 [index.html](index.html)，不需要安裝套件或啟動伺服器。每次選玩一關，每關四題；第 1–5 關不限時，第 6 關可選倒數或不限時；按學生程度選關，約 3–5 分鐘完成。

## 六個關卡

- 水果認一認：看圖認讀水果名稱。
- 特徵配一配：辨認水果的顏色或味道。
- 小小介紹員：用選單組成「我想介紹……」的描述句。
- 又……又……句子隊：選擇以兩個特徵組成的句子。
- 神秘水果猜猜看：由單一顏色或味道線索反向猜水果，答對才揭曉圖示。
- 倒數水果挑戰：由兩個特徵猜水果；限時兩分鐘或一分三十秒，也可選不限時，倒數可暫停。

關卡 1–4 練習六種常見水果；關卡 5–6 另加入西瓜、菠蘿、芒果、車厘子、梨和藍莓作隨機題目。

答錯可重試，每題答對後由學生按「下一題」，不會因反應速度受罰。

## 語音及操作

- 使用瀏覽器內置語音朗讀，語音語言設為 `zh-HK`；能否找到香港粵語聲線視乎裝置和瀏覽器。
- 只在裝置提供香港粵語（`zh-HK`）聲線時播放語音，不會以其他中文聲線代替；沒有相符聲線時會顯示文字提示。
- 題目、每個答案選項、組句詞語及答錯提示都設有朗讀控制；語音仍使用裝置的 `zh-HK` 聲線，聲線延遲載入時會自動重試。
- 第三關提供香港粵語語音輸入。語音辨認功能的瀏覽器支援不一，通常需要允許麥克風，部分瀏覽器要求在 HTTPS 或 localhost 使用；不支援時可用選單完成，不影響遊戲。
- 可用鍵盤、觸控或互動白板操作；按鈕和選單皆為原生控制項，並設有可見焦點、大型觸控區、重聽、文字放大和減少動畫偏好。
- 水果圖示使用系統 emoji；不同裝置外觀可能略有差異。

## 課堂及共融教學提示

活動採分層選關、短句指示、圖像加文字、重聽、正向回饋及不限時選項，讓學生按能力選擇挑戰和作答方式。倒數是可選的進階玩法，可暫停或改用不限時，不以操作速度評分。對閱讀困難，可先聽題再看文字；對動作協調或精細動作困難，可由同伴／教師代為觸控或用鍵盤、選單及語音，不以操作速度評分。學生可在共同課堂活動中完成同一主題，但獲得不同程度的提示和表達支援。

此設計以 WCAG 2.2、UDL、SETT 及香港教育局融合教育和特殊教育需要的課堂支援方向作為設計參考，不代表已完成正式合規認證。部署前仍應按學生個別需要、學校裝置和輔助科技作教師檢視，並以實際屏幕閱讀器、語音及鍵盤使用情況作測試。
